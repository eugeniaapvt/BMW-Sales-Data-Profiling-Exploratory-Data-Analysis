# BMW Sales Data Profiling

Data profiling pada dataset penjualan BMW periode 2010–2024 menggunakan Python dan ydata-profiling.

## Dataset

Dataset yang digunakan adalah BMW Sales Data (2010–2024), yang berisi data penjualan BMW pada periode 2010 hingga 2024.

## Data Exploration

Tahap awal dilakukan untuk memahami struktur dataset melalui:

- Dataset dimension (shape)
- Data types
- Data preview

## Data Profiling

Automated data profiling dilakukan menggunakan `ydata-profiling` untuk memperoleh gambaran menyeluruh mengenai karakteristik dataset.

Profiling report mencakup informasi mengenai struktur dan karakteristik variabel dalam dataset.

## Tools

- Python
- Pandas
- NumPy
- ydata-profiling
- Google Colab

## Usage

Notebook utama:

`Profilling_Data_BMW_Sales_2010_2024.ipynb`

Notebook berisi proses loading dataset, data exploration, dan automated data profiling.

## Results

Hasil profiling disimpan dalam bentuk HTML report:

`results/bmw_profiling_report.html`

Report dapat digunakan untuk melihat ringkasan karakteristik dataset secara lebih menyeluruh.
